# P4 时间与重试完备

**目标**：把「到点发生的事」和「失败了怎么办」从够用变成完整。

## 交付物

- 持久化 timer：`ctx.sleep(d)` → `StartTimer` / `TimerStarted` → 一行 `tasks(task_type=TIMER, visible_at = TimerStarted.event_time + d)` → scanner 到期写 `TimerFired` + 排 WFT（ADR-0012）。
- `ActivityOptions`：`schedule_to_start` / `start_to_close` / `schedule_to_close` / `heartbeat` 四种 timeout + RetryPolicy 五字段（`initial_interval` / `backoff_coefficient` / `maximum_interval` / `maximum_attempts` / `non_retryable_error_types`）+ `next_retry_delay`（ADR-0013）。
- heartbeat：activity 侧可上报（携带 checkpoint），heartbeat 超时触发 `ActivityTaskTimedOut{HEARTBEAT}`。
- `LISTEN/NOTIFY` 唤醒 + poll 兜底（**充分利用 PostgreSQL** 的兑现项之一）。
- `wft_retry_backoff_cap` 配置化；主线示例插入 `ctx.sleep`。

## Gate

`scripts/verify-p4.sh`：

1. **timer 持久性**：排一个 5s timer，把两个 worker 全杀掉、重启，断言 `TimerFired` 出现在 `TimerStarted.event_time + 5s` **之后**且只有一个。
2. **退避序列**：单测对照公式逐项断言 `1s, 2s, 4s, … cap`。
3. **timeout 分类**：分别触发 `schedule_to_start` / `start_to_close` / `heartbeat`，断言写出的 `TimeoutType` 正确。
4. **non_retryable 精确匹配**：`ChargeDeclined` 不重试；`charge_declined`（不同字符串）**仍然重试**。
5. **NOTIFY 兜底**：正常时唤醒延迟 < 1s；人为让 NOTIFY 丢失后，任务仍在 poll 周期内被取走。

## 不做

Local Activity；面向用户的 `CancelTimer` API（timer 只能自然到期）。
