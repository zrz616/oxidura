# M1 纯内存重放内核

**目标**：不连数据库，证明「给定历史 → 重放 → 产出命令」这套语义是对的。

## 交付物

- `Event` / `Command` 枚举与 `HistoryEvent`（ADR-0005、ADR-0006）。
- `apply_commands(...)` 纯函数（ADR-0008）。
- `replay()`：同步 poll-to-quiescence + `PollBudget`（ADR-0003）。
- `WorkflowContext`（`Rc<RefCell<Inner>>`，按值传）：`execute_activity` / `sleep` / `now` / `random` / `uuid` / `side_effect` / `info` / `is_replaying` / `logger`（ADR-0009）。
- 匹配器：严格顺序 + `is_command_correlated` 谓词 + AsyncEvent 分流**接口**（signal 本身 P5 才实现）。
- `NonDeterminism` 错误；每轮重放用 `catch_unwind` 包裹。
- 内存 `TestWorkflowEnvironment`：虚拟时钟 `advance_time(d)`、`activity_result` / `fail_activity` 注入、多轮驱动到终态。
- `examples/m1_replay.rs`。

## Gate

`scripts/verify-m1.sh`：`cargo nextest run -p oxidura-core` exit 0，且**下列测试全部存在并通过**（缺一即不合格）：

| 测试 | 断言 |
|---|---|
| `replay_multi_round_*` | 多轮驱动后终态一致；第二轮的 `ctx.now()` 与第一轮不同 |
| `nondeterminism_added_activity` | 报 `NonDeterminism`，且 `at_event_id` 指向那一处 |
| `nondeterminism_removed_activity` | 同上 |
| `nondeterminism_reordered_activities` | 同上 |
| `nondeterminism_changed_timer_duration` | 同上 |
| `apply_commands_*` | 事件序列与 `workflow_task_completed_event_id` / `scheduled_event_id` 回指正确 |
| `poll_budget_exceeded` | 自唤醒的 future 被 `PollBudget` 截断 |
| `pending_command_at_close` | workflow 已闭合但仍有未决命令 → 报错（**不静默丢弃**） |
| `side_effect_replayed_not_rerun` | 用计数器断言闭包重放时**不重跑** |
| `skip_whitelist_*` | 引擎产物事件被跳过而不错报非确定性 |

另有：`examples/m1_replay.rs` 可运行并打印两轮历史与各自产出的命令。

## 不做

数据库、async runtime、proc-macro、真实的 signal/query/child/CAN。
